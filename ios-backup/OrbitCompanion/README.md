# Orbit Companion for iPhone

Open `OrbitCompanion.xcodeproj` in Xcode. Choose an Apple development team, change the bundle identifier if needed, and run it on a simulator or iPhone.

The companion supports HTTPS login, session restoration, service status, internal task creation, recent task viewing, pull-to-refresh, and owner emergency pause/resume. Passwords are not saved by the app. Account registration, recovery, backups, OAuth, and standards-based Web Push remain in the installed web app.

This source project is not a signed App Store release. Test a real-device archive and complete Apple's signing, privacy, icon, metadata, and review requirements before distribution.
