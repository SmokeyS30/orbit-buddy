# Orbit Buddy — iOS App (Capacitor)

This is the Capacitor wrapper for Orbit Buddy. It packages the PWA (`public/`) as a native iOS app for App Store distribution.

## Setup (on your Mac, one time)

```bash
# Install dependencies
npm install

# Generate the iOS project
npx cap add ios

# Open in Xcode
npx cap open ios
```

## Building

1. Open `ios/App/App.xcworkspace` in Xcode (use `.xcworkspace`, not `.xcodeproj`)
2. Select your Apple Developer team under Signing & Capabilities
3. Bundle ID: `com.smokeys30.orbitbuddy` (configured in `capacitor.config.ts`)
4. Run on your iPhone (⌘R) to test

## Updating

**After changing frontend files** (`public/`):
```bash
npx cap sync ios
```
Then rebuild in Xcode.

**Backend changes** (server.js, src/): Deploy via Render as normal. No app update needed.

## App Store Submission

1. In Xcode: Product → Archive
2. Distribute App → App Store Connect
3. Upload to TestFlight for testing
4. Submit for App Store review

## Notes

- The `ios/` directory is generated by Capacitor — do not edit it directly. Change `capacitor.config.ts` and re-sync.
- Push notifications: The `@capacitor/push-notifications` plugin is included. Web Push continues to work; native APNs integration is a future enhancement.
- The old hand-written Swift app is preserved at `ios/OrbitCompanion/` for reference (not part of this build).
