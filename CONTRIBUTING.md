# Contributing

Thank you for helping make Orbit Buddy more useful and safer.

1. Fork the repository and create a focused branch.
2. Run `npm run check` before opening a pull request.
3. Describe behavior changes, tests, and any security or privacy impact.
4. Do not add telemetry, advertising, hidden network requests, or automatic external actions.
5. New connectors must be disabled by default, request the minimum permissions, show the exact proposed action, and support revocation.

By contributing, you agree that your contribution is licensed under Apache-2.0.
